# Flatpak

App ID: `io.github.lemonxah.ZestBay` (KDE runtime 6.11, freedesktop 25.08 base).

| File | Purpose |
|---|---|
| `io.github.lemonxah.ZestBay.yml` | Manifest: builds the LV2 stack (lv2, zix, serd, sord, sratom, lilv, suil), then ZestBay |
| `io.github.lemonxah.ZestBay.desktop` | Desktop entry (icon named after the app id) |
| `io.github.lemonxah.ZestBay.metainfo.xml` | AppStream metadata; add a `<release>` for each version |
| `icons/` | Square app and tray icons, generated by `images/make-icons.py` |
| `cargo-sources.json` | Vendored crates for the offline build; generated, see below |

## Building locally

Tools: `flatpak-builder`, and `flatpak-cargo-generator.py` from
[flatpak-builder-tools](https://github.com/flatpak/flatpak-builder-tools/tree/master/cargo)
on your `PATH` (it needs the Python packages `aiohttp` and `tomlkit`).

```sh
just flatpak        # regenerates cargo-sources.json, builds, installs for your user
flatpak run io.github.lemonxah.ZestBay
```

`cargo-sources.json` must be regenerated (`just flatpak-sources`) whenever
`Cargo.lock` changes, because the Flatpak build has no network access.

The manifest builds from the working tree (`type: dir`). For Flathub, switch
the ZestBay source to the release tarball (commented in the manifest) and
ship `cargo-sources.json` next to it.

## Sandbox notes

- **PipeWire**: `--filesystem=xdg-run/pipewire-0` gives access to the whole
  graph, as other patchbays on Flathub do.
- **Plugin editors** are X11 windows, so the app has the full X11 socket.
- **Plugins** are searched in `~/.lv2`, `~/.clap`, `~/.vst3`,
  `$LV2_PATH`/`$CLAP_PATH`/`$VST3_PATH`, `/app/extensions/Plugins/{lv2,clap,vst3}`
  (Flatpak plugin extensions) and the host's `/usr/lib*/{lv2,clap,vst3}` via
  `/run/host/usr` (`--filesystem=host-os:ro`). Host plugins built against
  distro libraries may fail to load in the runtime; the sandbox probe keeps
  that from crashing ZestBay. Flathub reviewers may ask about `host-os` and
  `home`; both exist so plugins and their data can be found.
- **LV2 UIs**: suil is built with the GTK 3 and X11 wrappers only, so Qt5,
  GTK2 and GTK4 LV2 UIs are not available in the Flatpak.
- **Config** lives in `~/.var/app/io.github.lemonxah.ZestBay/config/zestbay`,
  separate from a native install's `~/.config/zestbay`. Copy it over to keep
  your rules, layout and plugins.
